# CS2 Assistant 0.4.0

Добавлен обмен отдельными материалами между друзьями.

1. Открой материал и нажми **«Поделиться»**. Кнопка также есть на карточке.
2. Отправь полученный файл **`.cs2material`** другу любым удобным способом.
3. Друг нажимает **«Импорт материала»** в боковой панели, выбирает файл и подтверждает добавление.

Материал добавляется в нужную карту и категорию и сразу открывается. Переносятся текст, теги, скриншоты, способы броска и все варианты раскида. Нужная пользовательская категория создаётся автоматически; совместимая категория с тем же названием используется повторно.

Существующая библиотека и настройки не заменяются. Импорт всегда создаёт новую копию: повторная загрузка того же файла добавляет ещё один материал. При конфликте типов пользовательских категорий создаётся отдельная категория с суффиксом.

Файл содержит только выбранный материал. Другие записи, на которые ссылается Markdown, автоматически не включаются. Для обмена нужна версия 0.4.0 или новее у обоих пользователей.

Прошли 19 тестов, TypeScript, production-сборка и сценарии Electron: экспорт, импорт со скриншотами, отмена, сохранность библиотеки и отказ от неподходящего файла. Portable EXE и SHA-256 приложены к релизу.
