# CS2 Assistant 0.3.1

Заменён логотип тёмной темы на обновлённый вариант: светлый знак на чёрном фоне. Обновлены логотип интерфейса, иконка окна и иконка portable EXE.

Скачайте `CS2-Assistant-0.3.1-portable.exe` и запустите. Существующая библиотека и настройки сохраняются. Функции версии 0.3.0 доступны без изменений.

Сборка проверена TypeScript и production-сборкой. Контрольная сумма SHA-256 приложена отдельным файлом.
