## Начальный экран

Начальный экран состоит из квадратных плиток с названием карт из cs2 (Dust 2, mirage, nuke, ancient, inferno, anubis, cache). При нажати попадаем на следующую страницу (например mirage)на которой также будут плитки но уже (смоки, хае, флеш, молотов, позиции(a, b, mid, con, short), тактики, полезные фишки). При нажатии например на смоки появляется список состоящий из карточек смоков

Главная страница -> Страница карты -> список -> страница эелемента/орма добавления
### Списки
Список состоящий из карточек. Сверху кнопка "Add utility" при нажати мы попадаем в форму добавления новой элемента

Форма для гранат состоит из:
1. Название
2. От куда и куда (два текстовых поля ввода)
3. Три плитки с плюсиком внутри предназначеные для добавления скрина (должна быть возможность добавить больше скринов)
4. Выпадающий список всех способов броска (например jumptrow + ctrl) и возможность добавить свой способ через текстовое поле (кнопочка с плюсиком)

Форма для позиций, тактик, полезных фишек:
1. Название
2. Скрины
3. тексотовое поле Markdown

Карточка гранат состоит из:
 1. Скрина смока
 2. Названия в формате от куда и куда (с т -> в джангл)
 3. Способ броска (например left click)
 4. справа две кнопки (удалить и редактировать)

Карточка  позиций, тактик, полезных фишек и т.п. состоит из:
1. Название
2. Кнопки (удалить и редактировать)

При нажатии на карточку мы попадаем на страницу гранаты где есть несколько скриншотов в определенном порядке где:

1. Позиция где нужно стоять
2. Позиция для прицела
3. Сам смок или другая любая граната

Если страница предназначена  для тактик, позиций и т.д. то там должео быть
1. Название
2. Скриншоты
3. Описание (Markdown)


### Sidebar

1. Стрельба (пока оставь пустым)
2. Пики (пока оставь пустым)
3. Консольные команды (спсок с карточками но без отдельных страниц для каждой команды)
- Нзвание
- Команда
- Три кнопки (копировать, редактировать, удалить)
4. прицелы (пока оставь пустым)
