# CS2 Assistant 0.3.0

Офлайн-справочник для Windows: скачайте `CS2-Assistant-0.3.0-portable.exe` и запустите. Установка не нужна. Существующая библиотека подхватывается автоматически; базы 0.1/0.2 поддерживаются.

## Новое

- Руководство: темы и множество Markdown-подтем вместо отдельных пустых разделов «Стрельба» и «Пики».
- Внутренние ссылки на материалы и подтемы: поиск и вставка в редакторе, переходы по ID, история назад/вперёд с восстановлением прокрутки.
- Оранжевая и светлая темы, обновлённые логотипы. Чёрная тема по умолчанию и чёрная иконка EXE; зелёная тема удалена.
- «Лайнапы» переименованы в «Раскиды».

## Исправления

- У флешек результат необязателен; редактор предлагает позицию и прицеливание.
- Более толстая обводка способа броска на изображении.
- Исправлены смещение картинок в карточках с тегами и обводка поля поиска.
- Полосы прокрутки скрыты, сама прокрутка работает.
- Снята проверка формата кода прицела: можно сохранять произвольный непустой текст.
- Обновлены README и инструкция по ссылкам.

## Данные и проверки

Схема базы обновлена до 3. Старые данные и ID сохраняются; зелёная тема заменяется чёрной. Перед обновлением можно экспортировать библиотеку; при первом сохранении исходная база также сохраняется в `library.json.bak`. Для отката к старой программе нужна копия старой базы.

Проверены миграции, 15 тестов данных, TypeScript, сборка и сценарии в Electron с отдельной временной базой: руководство, ссылки, история, несохранённые изменения, темы, вёрстка и резервные копии. EXE не подписан сертификатом. Контрольная сумма SHA-256 приложена отдельным файлом.
