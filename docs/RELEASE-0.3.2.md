# CS2 Assistant 0.3.2

Снято ограничение 100 МБ на общий размер базы: при чтении, сохранении и импорте резервной копии. Обновлены подсказки на трёх языках и README.

Размер библиотеки теперь зависит от доступной памяти и диска. Ограничения отдельных изображений и элементов остаются прежними. Формат базы не меняется, существующие данные сохраняются.

Проверены сохранение и повторное открытие базы объёмом более 100 МБ, тесты хранения, TypeScript и production-сборка. Скачайте portable EXE; контрольная сумма SHA-256 приложена отдельно.
