# CS2 Assistant 0.5.0

## Новое

- Фильтр по тегам над списком категории: только теги выбранной карты и категории, счётчик материалов, точное совпадение без учёта регистра и кнопка «Все теги». Выбор восстанавливается при возврате из материала.
- Отдельная необязательная обложка раскида. Она отображается на карточке и не заменяет скриншоты позиции, прицеливания или результата. Без обложки используется прежнее превью.
- Поле ссылки на YouTube при создании и редактировании материала. Плеер находится внизу материала, без автозапуска; поддерживаются youtu.be, обычные ссылки, Shorts, трансляции и время начала.
- Кнопка открытия видео на YouTube, если автор запретил встраивание или видео недоступно. Для просмотра видео нужен интернет; остальная библиотека работает офлайн.
- Обложка и ссылка на видео сохраняются в резервной копии и при отправке отдельного материала другу.
- Все новые элементы переведены на русский, английский и португальский. Обновлён README.

## Обновление

Скачайте `CS2-Assistant-0.5.0-portable.exe` и запустите вместо старого EXE. Библиотека остаётся в `%APPDATA%\CS2 Assistant`.

Схема базы обновлена до версии 4. Версии 1, 2 и 3 читаются с автоматической миграцией, без перезаписи при чтении; при первом сохранении предыдущая база попадает в `.bak`. Старые приложения не читают схему 4, поэтому перед обновлением полезно экспортировать резервную копию.

Новые `.cs2material` используют формат версии 2: получателю нужна версия приложения 0.5.0 или новее. Импорт файлов из 0.4.0 сохранён. Видео передаётся ссылкой, а не скачанным файлом.

## Проверено

- 22 теста данных, TypeScript и production-сборка.
- Сценарии Electron в отдельной базе: фильтр тегов, независимая обложка, сохранность скриншотов, проверка ссылки, отображение и удаление плеера, обмен материалами, миграции и резервные копии, существующие функции.
- Реальный YouTube-плеер загрузился и воспроизводил видео внутри Electron; проверено продвижение времени воспроизведения.

Windows portable-сборка не требует установки или Node.js. EXE не подписан сертификатом разработчика.
